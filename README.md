TelecomX - Análisis de evasión de clientes
Descripción

Este proyecto realiza un análisis de datos con el objetivo de identificar los factores asociados a la evasión de clientes (churn) en la empresa TelecomX. A partir de los datos proporcionados en formato JSON, se llevó a cabo un proceso de exploración, limpieza, transformación y análisis para comprender el comportamiento de los clientes y detectar patrones relacionados con la cancelación del servicio.

Objetivo

Analizar las características de los clientes y los servicios contratados para identificar los principales factores que influyen en la evasión y proponer recomendaciones orientadas a mejorar la retención de clientes.

Tecnologías utilizadas

Python

Pandas

Matplotlib

Google Colab / Jupyter Notebook

Proceso de análisis

El proyecto se desarrolló siguiendo las siguientes etapas:

Extracción de datos desde la API.

Exploración y comprensión del dataset.

Limpieza y preparación de los datos.

Creación de nuevas variables para el análisis.

Análisis descriptivo y visualización de datos.

Identificación de patrones asociados al churn.

Resultados

El análisis permitió identificar que la evasión de clientes está asociada principalmente con contratos de corto plazo, baja adopción de servicios adicionales, menor antigüedad del cliente y ciertos patrones de facturación.
